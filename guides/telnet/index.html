تفكيك جلسة Telnet

Dissecting a Telnet session

نتصل بخادم Telnet ونقرأ تفاوض الخيارات، ومحاولة مصادقة NTLM، وتسجيل الدخول حرفًا حرفًا.

بانتظار ملف الالتقاطالقيم منقولة من التقرير ولم يُتحقق منها، لأن ملف الالتقاط غير متوفر.

نظرة عامة

  • أوامر IAC: WILL و DO و SB و SE
  • خيار Echo
  • مصادقة NTLM داخل Telnet
  • لماذا استُبدل Telnet بـ SSH

البرامج

  • Wiresharkالالتقاطwww.wireshark.org
  • VMware Workstation Proالأجهزة الافتراضيةwww.vmware.com
  • أمر telnet في Windowsعميل Telnet المدمج في Windowslearn.microsoft.com

استُخدم في التقرير Windows Server 2012 R2 كخادم. آخر إصدار من Windows Server فيه خدمة Telnet Server هو 2012 R2، وقد انتهى دعمه في أكتوبر 2023. للتجربة الحديثة يمكن تشغيل خادم Telnet على Linux داخل المختبر فقط.

التثبيت والتجهيز

  1. فعّل عميل Telnet على Windows

    من موجه أوامر بصلاحيات المسؤول:

    cmd
    dism /online /Enable-Feature /FeatureName:TelnetClient

  2. فعّل خادم Telnet على Windows Server 2012 R2

    من PowerShell:

    powershell
    Install-WindowsFeature Telnet-Server
Set-Service TlntSvr -StartupType Manual
Start-Service TlntSvr

المخطط

العناوين والمنافذ وعناوين MAC من التقرير. لم أستطع التحقق منها لأن ملف الالتقاط غير متوفر.

التنفيذ خطوة بخطوة

  1. ابدأ الالتقاط ثم اتصل

    cmd
    telnet 189.120.0.58
    • telnet <IP>يتصل على المنفذ 23 افتراضيًا

  2. اقرأ أول رسالة من الخادم

    حسب التقرير، أرسل الخادم سبعة طلبات في رسالة واحدة. كل طلب يبدأ بـ FF (IAC):

    text
    ff fd 25   DO   Authentication Option
ff fb 01   WILL Echo
ff fb 03   WILL Suppress Go Ahead
ff fd 27   DO   New Environment Option
ff fd 1f   DO   Negotiate About Window Size
ff fd 00   DO   Binary Transmission
ff fb 00   WILL Binary Transmission
    • FFIAC: البايت التالي أمر
    • FB / FDWILL / DO
    • FA … F0بداية ونهاية خيار فرعي

  3. لاحظ حجم النافذة

    أرسل العميل حسب التقرير: ff fa 1f 00 50 00 14 ff f0. القيمتان 0x0050 و 0x0014 تعنيان 80 عمودًا و 20 سطرًا.

  4. تابع محاولة NTLM

    داخل خيار Authentication يظهر النص NTLMSSP. حسب التقرير رفض الخادم المصادقة التلقائية وطلب اسم المستخدم وكلمة المرور.

  5. سجّل الدخول وراقب الحروف

    كل حرف تكتبه يُرسل في حزمة مستقلة، والخادم يعيده (Echo) ما عدا حروف كلمة المرور. لكنها تمر على الشبكة بنص واضح.

قائمة التحقق

أخطاء شائعة وحلولها

'telnet' is not recognized

السبب: عميل Telnet غير مفعّل.

الحل: فعّل الميزة TelnetClient بالأمر في قسم التثبيت.

Connection refused على المنفذ 23

السبب: خدمة TlntSvr متوقفة.

الحل: شغّلها بالأمر Start-Service TlntSvr.

ping بين الجهازين يفشل

السبب: الجهازان على شبكتين مختلفتين في VMware، أو جدار الحماية في Windows يمنع ICMP.

الحل: تأكد أن بطاقة الشبكة في الجهازين على نفس الشبكة (VMnet نفسها)، وفعّل قاعدة File and Printer Sharing (Echo Request - ICMPv4-In).

Wireshark لا يعرض أي حزم

السبب: اخترت بطاقة شبكة غير التي يمر عليها الاتصال.

الحل: من شاشة البداية اختر البطاقة التي يتحرك مؤشر نشاطها أثناء الاتصال، ثم ابدأ الالتقاط قبل تنفيذ التجربة.

العربية

حلّلت جلسة Telnet بين Windows 7 و Windows Server 2012 R2: تفاوض الخيارات بأوامر IAC، ومحاولة مصادقة NTLM رفضها الخادم، ثم تسجيل الدخول حرفًا حرفًا. أهم ما خرجت به أن كلمة المرور ظهرت كاملة في الالتقاط رغم أنها لا تظهر على الشاشة، وهذا سبب انتقال الإدارة عن بعد إلى SSH.

English

Analysed a Telnet session between Windows 7 and Windows Server 2012 R2: IAC option negotiation, an NTLM authentication attempt rejected by the server, and a character-by-character login. The password was hidden on screen but fully readable in the capture, which is exactly why remote administration moved to SSH.
