Setup

  1. Use two machines on the same virtual network

    Same as the FTP project.

Steps

  1. Clear the ARP cache

    So the machine has to ask for the MAC again. Needs administrator rights:

    cmd
    arp -d *
    • arp -d *Deletes every entry

  2. Start capturing on the server

    wireshark
    arp || icmp

  3. Run ping

    The default Windows command sends four requests, which is what the capture shows:

    cmd
    ping 189.120.0.58
    • ping4 Echo requests by default

  4. Check the cache afterwards

    cmd
    arp -a
    • arp -aShows the table; the server's address should be listed

Useful Wireshark filters

  • arp.opcode == 1ARP requests
  • icmp.type == 8Echo request
  • eth.paddingFrames with padding

What the capture shows

  • Ask everyone, answer one

    Who has 189.120.0.58? Tell 189.120.0.57 goes to ff:ff:ff:ff:ff:ff, and the answer 189.120.0.58 is at 00:0c:29:38:c4:76 comes straight back.

  • 60 bytes vs 42

    The request reached the server as 60 bytes including 18 bytes of padding. The reply shows as 42 because it was captured on the server before its card added the padding.

  • 4 requests, 4 replies

    Sequence numbers 1, 2, 3, 4; every reply has TTL 128 and 32 bytes of data.

  • A constant checksum difference

    0x4d5a → 0x555a · 0x4d59 → 0x5559 · 0x4d58 → 0x5558 · 0x4d57 → 0x5557. The difference is always 0x0800, because the only field that changed is Type, from 8 to 0.

  • The server asks too

    After the replies: Who has 189.120.0.57? Tell 189.120.0.58. Each side keeps its own ARP table.

Troubleshooting

arp -d returns Access denied

The command needs administrator rights.

Fix: Open the command prompt with Run as administrator.

Ping between the two machines fails

The VMs are on different VMware networks, or Windows Firewall is blocking ICMP.

Fix: Put both network adapters on the same network (the same VMnet or LAN Segment), and enable the rule File and Printer Sharing (Echo Request - ICMPv4-In).

Wireshark shows no packets

You picked an adapter the traffic does not go through.

Fix: On the start screen pick the adapter whose activity graph moves during the test, and start capturing before you run it.
